# Resume the Dyla take-home

1. Read `docs/STATUS.md` (current phase, open decisions, next step, session history).
2. Skim `docs/PLAN.md` sections relevant to the current phase. Read `docs/PROJECT_BRIEF.md` only if context on the company/brief is needed.
3. Check the last few entries of `docs/DECISION_LOG.md` so you don't re-open settled decisions.
4. Run `git status` and `git log --oneline -5` to see uncommitted or recent work.
5. Summarise in ≤ 8 lines:
   - Current phase and what is done
   - Next step
   - Open decisions that block it (give a recommendation; I make the call)
6. Wait for my go-ahead before building anything.
